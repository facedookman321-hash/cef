# samp-cef 1.4.1 (client only, CEF 89)

Server plugin, `cef-api`, `cef-interface` and examples removed.

Build on GitHub: push to `main`/`master` or run Actions -> build-client. Download artifact `cef.zip` and extract into the GTA San Andreas folder (`cef.asi` + `cef/`).

Toolchain: `nightly-2021-10-04` (i686-pc-windows-msvc). CEF: 89.0.5 official `windows32` (no proprietary codecs). Needs DirectX SDK (June 2010), installed by the workflow.
